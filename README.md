# Responsive Travel Website

## ❤️ Giới thiệu

Thiết kế trang web du lịch đáp ứng sử dụng HTML, CSS và JavaScript. Trang web này bao gồm các hoạt hình khi cuộn trang và cuộn mượt mà ở mỗi phần. Nó được phát triển đầu tiên với phương pháp Mobile First, sau đó cho máy tính để bàn. Tương thích với tất cả các thiết bị di động và cung cấp giao diện người dùng đẹp và dễ chịu.

## 💫 Tính năng

- Thiết kế đáp ứng
- Hoạt hình khi cuộn trang
- Cuộn mượt mà ở mỗi phần
- Phương pháp phát triển Mobile First
- Tương thích với nhiều thiết bị
- Giao diện người dùng đẹp và dễ chịu

## 💻 Công nghệ

- HTML
- CSS
- JavaScript
